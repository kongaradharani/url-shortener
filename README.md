# URL Shortener SQL Project

## Description

A simple URL Shortener database project built using MySQL.

## Features

- Store original URLs
- Create short codes
- Track clicks
- View URL data

## Technology Used

- MySQL
- MySQL Workbench

## Database Table

### urls table

| Column | Description |
|---|---|
| id | Unique ID |
| original_url | Original website URL |
| short_code | Short URL code |
| clicks | Number of clicks |

## How to Run

1. Open MySQL Workbench
2. Open `url_shortener.sql`
3. Execute the SQL commands
4. View the URL data
